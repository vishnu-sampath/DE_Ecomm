# suppliers

## Description
Stores supplier and vendor master data.

## Grain
One row per supplier.

## Business Use Cases
- Supplier performance tracking
- Cost analysis
- Supply chain reporting

## Columns
- supplier_id: Unique identifier for the supplier
- supplier_name: Name of the supplier
- email: Supplier contact email
- phone: Supplier contact phone number
- city: City where the supplier is located
- state: State where the supplier is located
- country: Country where the supplier operates
