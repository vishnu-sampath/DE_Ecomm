# warehouses

## Description
Contains warehouse location and identification data.

## Grain
One row per warehouse.

## Business Use Cases
- Inventory distribution analysis
- Logistics and supply chain tracking

## Columns
- warehouse_id: Unique identifier for the warehouse
- warehouse_name: Name of the warehouse
- city: City where the warehouse is located
- state: State where the warehouse is located
- country: Country where the warehouse is located
